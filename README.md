# LUMÉ Fashion Store

LUMÉ is a modern and elegant fashion store website created using HTML and CSS.

## About the Project

This project is a fashion e-commerce website designed with a clean and minimal style. It includes a navigation bar, hero section, featured products, special offers, and a footer.

## Features

- Responsive navigation bar
- Hero section with "Discover Your Style"
- Featured collection section
- Product cards with prices
- Add to Cart buttons
- Special Offer section
- Newsletter subscription section
- Footer with quick links and social media icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome
